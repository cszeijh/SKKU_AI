STEP카메라
1

카메라 켜기

버튼을 누르면 허용 창이 뜨고, 내 모습이 화면에 나옵니다. 가장 먼저 확인할 것은 이것 하나입니다.

이렇게 말합니다

1단계만 만들어줘. 화면에 '카메라 시작' 버튼을 두고, 누르면 카메라를 켜서 내 모습을 거울처럼 보여줘. 카메라를 허용하지 않으면 무엇을 해야 하는지 안내 문구를 보여줘. 손 인식과 소리는 아직 넣지 마.

눈과 귀로 확인
  • 크롬이나 엣지로 파일을 열었다.
  • 허용 창이 뜬다.
  • 내가 오른쪽으로 움직이면 화면 속 나도 오른쪽으로 간다.
  • 허용하지 않으면 안내 문구가 나온다.
안 될 때

"카메라가 안 켜져. 크롬에서 파일을 직접 열었고, 화면에는 '카메라에 접근할 수 없습니다'라고 나와. 원인을 찾아줘."

STEP손 찾기
2

손 찾기

카메라 화면 위에 손 관절의 점과 선(스켈레톤)이 그려지고, 펼친 손과 주먹이 글자로 구분됩니다.

이렇게 말합니다

2단계로 가자. 카메라 화면 위에 손 관절의 점과 선(스켈레톤)을 그려줘. 손을 펴면 '준비', 주먹을 쥐면 '연주'라는 글자를 크게 보여줘. 손 인식은 MediaPipe를 써줘. 한 손만 있어도 되어야 해. 소리는 아직 넣지 마.

눈과 귀로 확인
  • 손 위에 점과 선이 따라다닌다.
  • 손을 펴면 '준비'가 나온다.
  • 주먹을 쥐면 '연주'가 나온다.
  • 손을 화면 밖으로 빼면 글자가 사라진다.
안 될 때

"손이 잘 안 잡혀. 교실이 어둡고 손이 화면 아래에 걸쳐 있어. 손 전체가 보이게 하라는 안내 문구를 넣어줘."

STEP소리
3

소리 내기

주먹을 쥐는 순간 소리가 한 번 납니다. 쥔 채로 있으면 다시 나지 않습니다.

이렇게 말합니다

3단계. 주먹을 쥐는 순간 소리가 한 번 나게 해줘. 손을 다시 펴기 전에는 소리가 또 나면 안 돼. 소리 파일은 쓰지 말고 브라우저에서 직접 만들어줘. '소리 켜기' 버튼도 넣어줘.

눈과 귀로 확인
  • '소리 켜기'를 누른 뒤 주먹을 쥐면 소리가 난다.
  • 쥔 채로 있으면 소리가 다시 나지 않는다.
  • 손을 펴고 다시 쥐면 또 난다.
  • 컴퓨터 음량이 켜져 있다.
안 될 때

브라우저는 버튼을 누르기 전에는 소리를 막습니다. 그래도 안 나면 F12 키를 누르고, Console 탭의 빨간 글자를 복사해서 붙입니다.

STEP음과 악기
4

음과 악기

화면을 여덟 칸으로 나누고, 손이 있는 칸의 음이 납니다. 악기를 바꾸면 같은 동작으로 다른 소리가 납니다.

이렇게 말합니다

4단계. 화면을 세로 여덟 칸으로 나누고, 손이 있는 칸을 강조해줘. 칸마다 다른 음이 나게 하고, 주먹을 쥐면 그 칸의 음이 나게 해줘. 악기는 드럼, 베이스, 화음, 멜로디 중에 고를 수 있게 해줘.

눈과 귀로 확인
  • 칸이 여덟 개 보인다.
  • 손을 옮기면 강조되는 칸이 바뀐다.
  • 칸마다 음이 다르다.
  • 악기를 바꾸면 소리의 느낌이 달라진다.
안 될 때

"왼쪽으로 움직이면 오른쪽 칸이 켜져. 화면은 거울인데 칸 방향만 반대인 것 같아. 같은 문제가 다른 곳에도 있는지 같이 봐줘."

한 손

카메라가 부담될 때

이렇게 바뀝니다카메라 영상을 숨기고 손의 선만 보이는 선택이 생깁니다.

강의용으로 구성한 예시입니다. 이 이유는 학생을 아는 선생님만 압니다.
